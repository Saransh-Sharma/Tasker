## A sustainable cadence

- **Capture continuously:** record the thought without over-organizing it.
- **Commit each morning:** choose a realistic day around fixed commitments.
- **Act deliberately:** start the next task, routine, or Focus session.
- **Repair early:** reduce scope when reality changes.
- **Close gently:** record outcomes and intentionally carry forward.
- **Review weekly:** use evidence to change the system, not judge yourself.
- **Restructure seasonally:** update areas, projects, goals, habits, cards, and reminders when responsibilities change.

The complete user journey is:

`capture → clarify → organize → place → act/track → recover → reflect → adapt`

## Safety boundaries

LifeBoard can organize health evidence but does not diagnose or replace professional care. It can organize money routines but does not provide financial advice. EVA may explain and propose, but you remain the approval boundary for consequential changes.
