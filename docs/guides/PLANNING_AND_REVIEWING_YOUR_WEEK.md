# Planning and Reviewing Your Week

> Classification: Canonical user guide
> Audience: Users balancing multiple areas or projects
> Capability status: Current workspace
> Source authority: [Plan and Focus](../product/PLAN_AND_FOCUS.md) and current This Week workspace
> Last verified: 2026-08-11

## Use the current This Week workspace

LifeBoard no longer uses a sequential weekly-planning wizard. Open Plan → Week or the weekly planning route to enter the current This Week workspace. Use week mode for normal planning and overdue mode when recovery is the primary job.

The source lanes are:

- **Overdue:** already missed its intended placement;
- **Inbox:** captured but not fully organized;
- **Anytime:** valid work with no concrete day.

The concrete planning horizon is Today and the next two days. **Later This Week** is a softer commitment for the remaining horizon; it should not pretend that an overloaded future day is precise.

## Plan the week

1. Read fixed meetings and each day’s capacity bar before moving tasks.
2. Write a short weekly intention that helps you reject low-value commitments.
3. Search/filter, then select source-lane tasks. Clarify duration, energy, readiness, context, or project before distribution if needed.
4. Place high-readiness tasks into concrete days around meetings. Put plausible but not yet scheduled work in Later This Week.
5. Use bulk distribution only after checking the preview. Placement persists immediately; a receipt records the change and supports Undo.
6. Leave uncommitted capacity. If the bar is overloaded, reduce, move, or unschedule instead of hiding the warning.

An empty source lane is success. A task can remain Anytime intentionally. Immediate persistence means dismissal does not discard already applied placement.

## Recover an overloaded or overdue week

Switch to overdue mode. For each item ask: Is it still needed? Is the next action clear? Does it belong to me? Does it need a concrete date?

- Complete work already done.
- Clarify vague outcomes.
- Move genuine near-term work into the concrete horizon.
- Return optional work to Anytime.
- Delete or archive work that no longer matters, after reading consequences.

If a bulk operation partially fails, keep the remaining selection and inspect the receipt. Do not repeat the entire batch blindly because successful items may already be persisted.

## Review the week

Open Weekly Review or Weekly Reflection:

1. Review outcomes, Focus history, capacity, habits/routines, goals, health/wellness signals, and Journal context.
2. Open evidence behind any insight. Treat sparse data as insufficient—not negative.
3. Separate recorded facts from your interpretation.
4. Note what created friction: excess load, unclear work, notification burden, energy mismatch, or structure.
5. Revise projects/goals, pause a habit, change a routine, or adjust working hours/reminders.
6. Carry forward intentionally and write the next week’s intention.

Health patterns are non-clinical and analytic relationships are non-causal. Use professional support for medical or financial decisions.
