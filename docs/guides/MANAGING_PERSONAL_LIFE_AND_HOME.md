# Managing Personal Life and Home

> Classification: Canonical user guide
> Audience: Users managing household and personal responsibilities
> Capability status: Current workspace; dedicated household administration is future
> Source authority: [Feature Catalog](../product/FEATURE_CATALOG.md)
> Last verified: 2026-08-13

## Build a practical personal system

Use Life Admin for recurring responsibilities and finite projects such as moving, travel preparation, or a home repair. Keep Health & Self, Relationships, Learning & Growth, Creativity & Fun, and Money separate when their review questions differ.

- Use tasks for errands, appointments, calls, renewals, and one-time maintenance.
- Use recurrence for genuinely repeating actions; use a routine when order matters.
- Use Notes/Knowledge for checklists, reference numbers, scans, warranties, recipes, and travel information.
- Use Life Moments for meaningful dates/countdowns with captured timezone and recurrence.
- Use tags such as `errand`, `phone`, or `home` to batch by context.

## Plan around real constraints

Select personal calendars so appointments appear as fixed commitments. Estimate travel/transitions manually where needed. Group errands with context filters, but do not overfill available time. Later This Week is appropriate for flexible household work; concrete days are for actual commitments.

Home’s Personal mode can emphasize tasks, routines, Life Moments, care, meals, and reflection. Add sensitive cards only with intentional Home consent. Removing a card never deletes its source records.

## Use routines for recurring responsibility

A morning, evening, weekly reset, departure, or home-closing routine can combine instruction, check-in, timer, task, habit, and choice steps. Pause/resume when interrupted. Partial completion is honest; do not mark linked tasks/habits twice. Edit the definition after the run if the order no longer fits.

## Store reference safely

Use folders, tags, smart collections, pinned/favorite notes, templates, links, attachments, and scanning. Secure notes can require biometric unlock. Trash supports restoration; permanent deletion is final after confirmation. Journal is better for private lived context; Notes are better for reusable facts and plans.

## Recover from accumulation

During weekly review, process overdue personal tasks, archive finished projects, pause noisy recurring work, and remove unused Home cards/reminders. Minimum Viable Day should retain essential care and one meaningful responsibility while deferring optional maintenance.

## Current limits

Dedicated inventories, bills/subscriptions, vehicles, warranties, travel itineraries, household ownership, and shared family planning are not current structured modules. You can represent them with existing projects/tasks/notes, but the richer requirements remain explicitly future in the [blueprint](../product/LIFEOS_FUTURE_BLUEPRINT.md).
