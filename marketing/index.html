Films

Every cut renders in three formats from the same code: 9:16 for Reels, TikTok, Shorts and the App Store; 16:9 for the site and YouTube; 1:1 for feeds. Each has a scored and a silent version, a poster frame and a contact sheet.

Set one: Drawn

"A real day, drawn." Every frame drawn in ink on warm paper: scraps of a life fold into one place, the app asks its own questions, plans break and EVA helps recover, the sun lands as the icon's eye.

How to render

cd marketing
bash build-all.sh                         # curate assets, build both sets in 3 formats, rebuild this page
bash teaser/build.sh advert-30s           # one film of set one
node teaser/render.mjs teaser/advert-30s.html --grid 24 --ar 9:16 --out teaser/out/grid   # a 24-frame sheet in seconds
node tools/build-catalog.mjs              # rebuild this page after any render

Needs Node 18+, ffmpeg and a Chromium; the scripts default to Playwright's Chrome for Testing on this Mac (set CHROME to override). Films are drawn at 12 fps on twos and packed to 24 fps with the hand-drawn-canvas-animation skill; the score is Web Audio written from the same timeline. Outputs live in each set's gitignored out/final.
